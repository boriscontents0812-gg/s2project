# 2126® — 100年後の世界 (The Century Shift Archive)

> **Unseen Studio® (https://unseen.co/)** のデザイン思想・UI構造・コード設計を忠実に再現した、100年後の未来（2126年）を直感的に体験できるインタラクティブWebサイト。

---

## 🌟 プロジェクトの特徴

1. **極めてわかりやすい日本語コピー**
   - 専門用語や難しい長文を徹底的に排除。「100年後のあたりまえ」が一瞬で伝わる、シンプルでパンチのあるテキストと巨大な数値メトリクスを採用。
   - 医療・寿命、テクノロジー・AI、エネルギー、都市・移動、宇宙開拓の5大テーマを収録。

2. **Unseen Studio® 完全インスパイアのUI / UX**
   - **インタラクティブ・ローダー**: `2 1 2 6` の立体ボックスアニメーション、ローディング進捗バー、サウンド選択ボタン（音声あり/なし）。
   - **カスタム・フルードカーソル**: スムーズな慣性追従、ドラッグ領域での「DRAG」バッジ、動画カードでの円形再生プログレスバッジ。
   - **Three.js WebGL 3D背景**: 浮遊する星雲パーティクルとホログラフィック・トーラスリング。マウスの視差（パララックス）およびスクロール速度に応じたワープ演出。
   - **デュアルタイポグラフィ・ホバー演出**: ナビゲーションにカーソルを合わせると、通常フォントが上部にスライドし、美麗なイタリック・セリフ体が下から現れるUnseenの代名詞的インタラクション。
   - **Web Audio API シンセサイザー**: 外部音声ファイルへの依存ゼロ。ブラウザ内部で生成される温かみのあるアンビエントドローン音と、UIホバー時のラチェット音・風切り音を実装。
   - **Lenis スムーススクロール**: 慣性のある滑らかなスクロールフィーリング。

3. **本物の実写（IRL）B-Roll映像の完全統合**
   - NASA等の公式アーカイブから厳選した高画質B-Roll動画（MP4）をローカル（`assets/videos/`）に配備：
     - `sample.mp4`: 細胞分裂・生命の再生（医療・寿命）
     - `robotics.mp4`: NASAヒューマノイドロボット Robonaut 実験室（AI・知能ロボット）
     - `energy.mp4`: NASA太陽フレア・プラズマダイナミクス（核融合・無償エネルギー）
     - `city.mp4`: NASA夜の地球・輝く都市メガグリッド（超音速移動・空中都市）
     - `space.mp4`: NASAアルテミス月探査ロケット打ち上げ（月面リゾート・宇宙移住）
   - ホバーでの自動プレビュー ＆ クリックでのシネマティック全画面シアターモーダル。

4. **インタラクティブ・コンテンツ**
   - **いま（2026）vs 100年後（2126）比較マトリクス**
   - **100年後のあなた診断（Age & Future Simulator）**: 現在の年齢を入れると、2126年の実年齢・肉体年齢と未来の1日スケジュールを即座にシミュレーション。

## 🚀 起動方法

### 方法1: ローカルサーバーで実行（推奨）
動画のストリーミングやシーク操作を最適に行うため、内蔵の軽量サーバーを起動します。

```bash
node server.js
```
ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

### 方法2: ブラウザで直接開く
`index.html` をダブルクリックして任意のモダンブラウザ（Chrome, Edge, Safari, Firefox）で開くだけでも動作します。

```
        ├── city.mp4        # 夜の地球・メガシティ
        ├── energy.mp4      # プラズマ・核融合

```
